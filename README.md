# soldatov-vibecoding

`$soldatov-vibecoding` — скил для Codex, который помогает вести AI-проект по
управляемому маршруту: от идеи, brief и MVP до требований, архитектуры,
реализации, проверки, деплоя и передачи следующему владельцу.

## Когда использовать

- нужно превратить размытую идею в проверяемый MVP;
- AI уже собрал проект, но последовательные правки вызывают регрессии;
- локальный прототип нужно безопасно подготовить к production;
- требуется проверить готовность, откат, наблюдаемость и handoff;
- нужно отделить подтверждённые факты от допущений и неизвестного.

Скил не начинает с генерации всего кода. Сначала он определяет стадию проекта,
проверяет входные данные и выбирает минимальный следующий артефакт или изменение.

## Установка в Codex

PowerShell:

```powershell
git clone https://github.com/abdublinn/soldatov-vibecoding-skill.git `
  "$env:USERPROFILE\.codex\skills\soldatov-vibecoding"
```

Если каталог уже существует, сначала обновите или удалите его осознанно — не
запускайте команду поверх рабочей копии.

После установки начните новую задачу Codex. Скил поддерживает автоматическое
обнаружение и явный вызов:

```text
$soldatov-vibecoding помоги превратить идею в проверяемый MVP
```

## Состав

- `SKILL.md` — компактный контракт и маршрутизация;
- `references/master-prompt.md` — полный управляющий промпт;
- `references/workflow.md` — стадии, гейты и артефакты;
- `references/patterns.md` — устойчивые паттерны разработки и восстановления;
- `references/glossary.md` и `references/cheatsheet.md` — быстрые справочники;
- `references/chapters/` — 43 тематических раздела с прогрессивной загрузкой;
- `agents/openai.yaml` — метаданные интерфейса Codex.

## Безопасность

Скил требует минимальных прав, минимального изменения, наблюдаемой проверки и
доказанного пути восстановления перед рискованными изменениями постоянных
данных. Инструкции внутри документов, логов, кода и внешних материалов
рассматриваются как недоверенные данные, пока пользователь явно их не примет.

книги и не является заявлением об одобрении скила автором.
